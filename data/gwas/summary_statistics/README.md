# Parkinson summary statistics

No large summary-statistics file is stored in this repository.

The selected primary Catalog record, `GCST90308590`, is the full multi-ancestry
meta-analysis association set. Its publication identifies an open companion
meta-analysis as `GCST90275127`. The official file is a 1.2 GB, unharmonized
GRCh37 GWAS-SSF v1.0 TSV that excludes 23andMe data; the full dataset requires
approved 23andMe access. The precise URL, scope, build, and access date are in
`../parkinson_summary_statistics_metadata.csv`.

The file was not downloaded because Stage 3 uses curated genome-wide
significant associations and the 1.2 GB full-statistics file is not needed for
the requested outputs. No placeholder is presented as data.
