# Current public website audit

The current website is a Vite/React/TypeScript single-page application using React Three Fiber and Three.js. `web/package-lock.json` fixes npm packages; `npm run dev` uses port 8000. The scientific pipeline supplies real Stage 6 Parkinson and Stage 10 multi-disease regional records, Stage 7 spatial robustness, Stage 8 Parkinson validation, Stage 9/10 biology, and AAL3 region metadata. The public data directory includes optimized JSON and downloadable CSVs. `scripts/validate_web_data.py` and Python/Vitest/Playwright tests already enforce several data contracts.

Reusable components include the disease/metric controls, legends, tooltip, region detail panel, scientific result tables, source metadata, desktop/mobile tests, and region-ID lookup. The current multi-disease selector and comparison represent ten completed analyses; five screened diseases are correctly excluded or under review. The older Parkinson-only wording in the pasted website brief predates those real Stage 10 results and should not cause their removal.

The critical replacement is the 3D geometry: `prepare_web_data.py` currently extracts rectilinear outer faces from 2 mm AAL3 voxels, yielding block-like surfaces with no true cortical folds. `BrainScene.tsx` then combines those faces into a colored brain. This geometry should be replaced, not cosmetically smoothed. The recommended architecture separates a higher-resolution continuous anatomical surface, AAL3-derived surface labels/region-ID mapping, and existing read-only research records. Other website gaps include route/shareable-state support, a fuller methods/data/biology/about/citations presentation, deployment instructions, release metadata, and final static screenshots.
