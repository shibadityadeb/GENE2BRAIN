# Static website deployment

The public GENE2BRAIN site is a Vite static application. Its build contains no server-side calculation, API secret, or dynamic scientific analysis. Deploy **only** the contents of `web/dist/` to a host that serves static files and supports an `index.html` fallback for the deep-link path `/dev/atlas-validation`.

## Preflight

From the repository root, run:

```bash
python scripts/validate_web_data.py
python scripts/validate_brain_region_mapping.py
cd web
npm ci
npm test
npm run build
npm run test:e2e
```

The build is generated by `npm run build` and its output is `web/dist/`. `npm run preview` serves it locally. Source JSON/CSV assets under `web/public/data/` are copied into `dist/data/`; do not omit that directory or substitute maps from another dataset. The main geometry JSON is about 21 MiB uncompressed; enable gzip or Brotli on the static host and allow long-lived caching for immutable data assets. The release metadata records SHA-256 digests for the canonical multidisease, geometry, and project files; compare them after deploying.

For a temporary ngrok preview of the dev server, set
`GENE2BRAIN_TUNNEL_HOST` to the exact hostname of the current HTTPS tunnel
before starting Vite (see [local instructions](README.md#run-locally)). The
allowlist deliberately rejects other Host headers. This setting is only for
the development/preview server; it is not a production-host configuration.

For a host without path fallback, the legacy validation URL `/?mode=atlas` works; main interactive links use URL query parameters for disease, metric, hemisphere, camera and region. Host the application at the domain root unless you update Vite's `base` and retest asset URLs and deep links.

## Public-facing caution

This is a research visualization of healthy-donor expression enrichment. It does not depict patient anatomy or demonstrate pathology or causality. The researcher identity, institutional affiliation, contact, and publication status are intentionally unfilled pending confirmation. The neuromaps transformation distribution identifies CC BY-NC-SA 4.0 terms, while Nilearn currently lists the fsaverage6 dataset's data license as unknown. Confirm surface-asset redistribution rights and appropriate derivative attribution/licensing before formal or commercial public release. Review the other atlas/data-source terms as well. No deployment command is run by this repository change.
